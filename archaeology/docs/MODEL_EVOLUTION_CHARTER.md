# MODEL Archaeology Charter — Version 0.1.0

**Inquiry:** What is being modeled, why, for whom, through which representations, and what changes between historical viewpoints and later revisions?

The **unit of comparison** is a bounded MODEL representation, not an image file or merely a customer-outcome word list.

| Dimension | Necessary question |
|---|---|
| Identity | What is the object of this model? |
| Boundary | What is inside, outside, and crossing? |
| Purpose | Whose decision should the model help explain or support? |
| Resolution | What is represented as an individual instance versus an abstract role/category? |
| Ontology | Which object types have distinct identities and definitions? |
| Relations | What are the directed/typed relationships and their evidence status? |
| Epistemology | What is source-observed, inferred, contradicted, proposed or unknown? |

**Change classification:** rename-only; concept-added; concept-split/merged; meaning-changed; abstracted; moved-to-interface; outside-new-scope; relationship-added/retyped; observer-shift; evidence-status-revised.

**Do not conflate:** Current vs Future (two design views), MODEL vs COO (whole vs outcome subdomain), 2006 source vs 2026 interpretation, customer reality vs supplier's model, customer driver vs desired outcome, supplier capability vs customer outcome, conversation vs contract vs realized benefit.

**Required provenance:** source artifact ID and original file SHA if available; publication date precision; original wording; interpretation date; mapping rationale; explicit unresolved counterexample.

**Proposed review tests:** Is a category genuinely absent, or moved to an interface? Has a label been copied while the concept's identity changed? Does a new relation imply causality without evidence? Could the model make a correct No Match judgment? Does an added concept help answer a relevant competency question, or merely increase complexity?

**Improvement cannot be inferred from aesthetics, number of nodes, number of crosswalks, or later publication date.** To promote a model to canonical status, compare its ability to answer fixed questions, preserve contradictions, avoid unjustified equivalences, and support independent customer decisions.

The source materials are separately preserved in the five-blueprint archaeology. This repo contains derived public-safe representations.
